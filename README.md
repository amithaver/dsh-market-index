# DSH plugin market index

Индекс плагинов для DeepSeek Harness в формате market index v1.

- `index.json` — сам индекс: плагины, версии, совместимость с ядром DSH.
- Формат: `format: 1`, у каждого плагина `name`, `versions[]` (`version`, `publishTimestamp`, `source`, `engines.dsh`).

Подключение в DSH: «Плагины» → «Открыте для себя» → «Добавить источник индекса» → URL этого файла.

Плагины — сторонний код. Устанавливайте только те, чьим авторам доверяете: после установки они работают с вашими правами.
